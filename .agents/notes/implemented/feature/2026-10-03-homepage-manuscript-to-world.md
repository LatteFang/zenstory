# Agent Note: 首页以单一真实案例的“手稿到世界”舞台呈现

Status: implemented（2026-10-03 用户确认上线；逻辑与 CTA 落点见 [首页逻辑 note](2026-10-03-homepage-material-first-logic.md)）

## Problem

上一轮首页虽然复用了真实 README 视频，用户仍认为质感与 Hypit 差距很大：首屏被标题、两行说明、双按钮、安装框和备注占满，1440×900 下作品舞台只露出边缘；舞台把四个来源不同的画面拼在暗底上，没有主角，也看不出方法与产物的关系；米白营销页与海军蓝网格舞台之间没有贯穿的品牌语言；后半段回到同样的白卡与文字索引。独立 critic 按同 viewport 截图逐项判为不通过。

## Decision

首页使用自己的视觉系统，作用范围是 `<body data-page="home">`（`site-shell.mjs` 的 `page({ pageId, fonts })`），其他页面不变。字体为 Geist 与系统中文无衬线，路径和命令用 Geist Mono，只在首页通过 `HOME_FONTS` 加载；被引用的原著文字用中文衬线竖排。

品牌语法取自标志：页面是手稿纸色，舞台、作品放映带和收尾带是墨蓝“世界”，虚线奶油色故事线连接事物，标志的青色星芒是唯一的节点与项目符号。

首屏只保留一行主张、一行说明和一个主按钮（主按钮落点与安装命令的位置见 [首页逻辑 note](2026-10-03-homepage-material-first-logic.md)）；宽屏标题单行（`<br>` 在 ≥1100px 隐藏）。其下是一个单一真实案例的舞台，数据在 `content/showcases.json` 的 `story-game.chain`：novel-to-game 固定提交 `e2695b7` 的 `source/西游记.txt` 第五九回回目与开篇原文、`analysis/SOURCE_BIBLE.md` 中“西行是一条受约束的路”一行的原作与改编字段、`qa/evidence/browser/03_boss_command.jpg` 实机截图，以及游戏自带的悟空立绘 `build/app/assets/units/wukong.webp`。生成器校验这些链接都指向所属仓库的固定提交。可玩原型是主角，悟空从画面中跨出；手稿斜放在左，规则纸条压在手稿下缘；故事线从手稿连到关卡名称。图说只有一行案例标题和三个短行动（见首页逻辑 note），原文的回目与公版来源写在舞台原著链接的 `title` 上；其他独立案例在下方放映带。

放映带的五个案例共用一个媒体框（12px 圆角、细边、阴影），竖屏短剧居中叠在自身 poster 的模糊背景上，不用手机外壳。HTML 保留原生 controls；内联脚本在有 JavaScript 时以一个播放键代替原生控制条，点击后才播放并交回原生控制。输入与产物用带两个星芒节点的虚线条呈现；方法是文字链接，直接观看、试玩与来源合为一行次要链接。写作视频 poster 改用第 23 秒正文输出，短剧用第 50 秒系统面板，Plateau 用第 13.5 秒取景框。

后半段：工具区改为一张表（工具名、做什么、说明、链接），使用环境是第二张表；路径区为不等宽网格，“已经有小说”是手稿纸色大格，改编分支是两张并列选项；知识区保持左侧标题与站内搜索表单（GET `/guides?q=`）配右侧四层；收尾改为墨蓝带接到页脚，关系图使用同一条虚线故事线（关系图的节点与说明见首页逻辑 note）。

## Alternatives considered

- **四个工具各一帧的作品墙**：最强的理由是首屏就能看到四种成果。被否决，因为四种来源、比例与色调不同的截图并置就是拼贴，读不出方法到产物的关系，也容易被误读为同一故事的改编链。
- **全站暗色首页（类似 Hypit 默认暗色）**：最强的理由是媒体在暗场最出色、风格统一最容易。被否决，因为首页应继续尊重 `prefers-color-scheme`，暗场只用于“世界”和媒体。
- **左文右图分栏首屏**：最强的理由是首屏能同时放下更多文字。被否决，因为上一版正是这种结构并被认为像博客卡片；置中短主张加整幅舞台更能形成视觉焦点。
- **去掉 HTML 中的 controls、只靠脚本播放**：最强的理由是去掉双重播放提示最彻底。被否决，因为无 JavaScript 时将无法播放，测试也要求保守的原生播放。

## Consequences

- 首屏在 1440×900 内完整呈现主张、动作和真实案例；390×844 首屏可见案例链与游戏画面。所有作品文字与来源仍是静态 HTML。
- 新增来自 novel-to-game 固定提交的两份媒体（实机截图 184 KB、悟空立绘 WebP 85 KB），首页首屏图片字节增加；立绘在 ≤960px 缩小。
- 首页与其他页面暂时是两套视觉语言，导航到 `/guides` 等页面会有风格切换；若方向被接受，需要另一轮全站推广。
- 英文页舞台中的规则纸条是对中文设定集的翻译，并注明“Translated from the Chinese source bible”。
- 视觉验收仍需用户本人看图；测试通过不代表审美通过。
